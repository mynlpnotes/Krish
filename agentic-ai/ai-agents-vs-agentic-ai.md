# AI Agents vs Agentic AI

* AI agents are individual tools that perform specific tasks, while agentic AI is a system that uses AI agents to collaborate and achieve a common goal
* Some agent might be for google search, some might be calculation&#x20;
* For Blogs Page:
  * YT Provides APIs
  * As soon as video is posted a trigger will come
  * Based on trigger we created multiple agents
  * 1 agent for transcript&#x20;
  * It will give it to next agent ⇒ Summarize
  * It will give it to next agent ⇒ Coder ⇒ This will format the code
  * This 2 outputs will go to another which which will combine both the outputs and create a blog page
  * The agents will also be interacting with each other
*   There are different platforms ⇒ LangChain, Agon, CrewAI
