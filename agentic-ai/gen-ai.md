# Gen AI

* Subset of ML and its main task is to generate new content
* Agentic AI is subset of Gen AI ⇒ The task is not just to generate new content but also solve complex workflows
* In ML we used to give input and give output, but if we give it anything which was output of training data then we wont get good output
* In DL the accuracy was better
* Example ⇒ In UPSC there are different 11 subjects and different rounds in exam, so for preparation different sources will be there
* So the person who has studies this will be like a UPSC model, so whatever question we give him, he will be able to answer
* If we ask any engineering question ⇒ Then we might not be able to answer
* LLM model is trained with huge data
* So if we give a prompt it will be able to give output and it will generate new content ⇒ so its generative model
* Training is done in 3 steps
*   Deepseek also used Reinforcement along with 3 steps, so it reduced training and increased inferencing also
