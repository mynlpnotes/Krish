# RGB vs HSV

**RGB:**

* Centre is 255, and as we move along the axes, it will decrease to 0
* So on the left plane, there will be some value of R and G but there wont be any value of B
* In the 2nd plane, there will be some value of R, G and some value of B as well
* In RGB, we cannot just target any particular color, if we want to change B, then R and B will also change as well
* To create any color, R G and B will have to be added, so its a additive model
*   There can be 16.7 million possible colours in RGB

**HSV:**

* Hue to color (Degree)
* Saturation of color (Percent)
* Value of color (brightness) (Percent)
* Cone kind of a structure, whereas RGB was cone
* Hue correspond to the color component, there is a 360 wheel
* So we can Red is from 330 to 30
* 0 means no saturation, so it means its while, as we increase the darker the color becomes
*   V is brightness&#x20;
