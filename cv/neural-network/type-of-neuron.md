# 🟢 Type of Neuron

1. <mark style="color:purple;background-color:purple;">**Single layer perceptron:**</mark>
   1. Can do binary classification
   2. Used for linear separable problems
2. <mark style="color:purple;background-color:purple;">**Multi layer perceptron:**</mark>
   1. More then one hidden layer
   2. Non linear activation function (ReLU, sigmoid, tanh)
   3. Can solve non linear problem

*   We can have input layer, hidden layer and output layer
