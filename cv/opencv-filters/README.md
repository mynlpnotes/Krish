# OpenCV Filters

* In the context of image processing, the terms "filter" and "kernel" are often used interchangeably.&#x20;
* They both refer to a small matrix of weights that is convolved with an image to produce a filtered output
* It is 2D and needs to be applied on each channel
* It can be of any size
* Used to enhance image
* Range of a pixel is from 0 to 255 -> so the value of kernels should not be too overwhelming so that the brightness exceeds 255
