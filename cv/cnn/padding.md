# Padding

* We might miss features at the corners of the image
* It can be due to size of kernel, stride
* Types of padding:
  * Same: After convolution also the size of the image is same as before&#x20;
  * Valid: No padding
  * Zero padding
  * 1 pixel passing
* We can pad with 0 or other colors also
