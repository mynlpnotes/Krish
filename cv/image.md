# Image

* <mark style="color:purple;background-color:purple;">**Image is 2D array of pixel values where each pixel represents the color information at a specific point**</mark>
* <mark style="color:purple;background-color:purple;">**Each pixel has value ranging from 0 to 255**</mark>
* <mark style="color:purple;background-color:purple;">**0 is darkest and 255 is brightest**</mark>
* <mark style="color:purple;background-color:purple;">**While pixel = 255, 255, 255**</mark>
* <mark style="color:purple;background-color:purple;">**Each pixel has 3 channels**</mark>
* Images can be grayscale or color images, where each pixel is represented by three or four values corresponding to the primary color channels
  * Digital image: Stored as a matrix of pixel values
  * Color image: Each pixel is represented as a tuple(255,0,0 -> Red)
* Fundamental of CV is image
* Fundamental of image is pixels
* Normally image has 3 channels - R, G and B
* In OpenCV the 1st channel is blue
