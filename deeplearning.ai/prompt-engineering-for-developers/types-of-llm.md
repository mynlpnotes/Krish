# Types of LLM

**Base LLM:**

* Has been trained to predict next word, based on text training data

**Instruction tuned LLM:**

* Trained to follow instructions
* We start with a base LLM that has been trained on a huge amount of data and further tune it with inputs and outputs that are instructions
* Further refined using RLHF - Reinforcement learning with Human feedback
* Trained to be helpful, harmless and honest
