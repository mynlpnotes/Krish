# 🚨 PyTorch Theory

\-----— Add from PDF here

* Open source developed by Meta
* Originally written in LUA
* Later written in python so became pytorch
* Can run on GPU, numpy cant run on GPU



**Features:**

* Supports multi dimensional arrays
* GPU support
* Auto gradient&#x20;
* Distributed training
* Easily integrated with other libraries



**PyTorch vs Tensorflow:**

* Pytorch is python based, tensorflow is also python based but has C++ core
* Pytorch is better and easier for research, tensorflow is better for deployment options
* Tensorflow is more widely used in production
* Both have strong performance
