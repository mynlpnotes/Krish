# GPT-1

* Generative pre-trained model
* Decoder only model
* By OpenAI in 2018
* Trained on book corpus dataset
* Able to generate text, translate language, write creative content

Main innovations:

* Unsupervised pre-training

**Drawbacks:**

* Failed to reason over multiple  &#x20;turns of dialogue and could not track long-term dependencies in text
