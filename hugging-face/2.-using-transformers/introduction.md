# 🟢 Introduction

* Transformers library is to provide a <mark style="color:purple;background-color:purple;">**single API through which any Transformer model can be loaded, trained, and saved**</mark>
* Advantages:
  * Ease of use: Downloading, loading, and using any SOTA can be done in 2 lines of code
  * Flexibility: All models are simply pytorch or tensorflow models
  * Simplicity
