# Choose min points

| **Method**                                                                              | **Description**                                                                                                                                                                                                                                                                               | **Recommendation**                                                                                    |
| --------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------- |
| <mark style="color:purple;background-color:purple;">**Dimensionality Heuristic**</mark> | <mark style="color:purple;background-color:purple;">Set</mark> <mark style="color:purple;background-color:purple;"></mark><mark style="color:purple;background-color:purple;">**`min_samples = 2 * number of dimensions`**</mark><mark style="color:purple;background-color:purple;">.</mark> | Start with **4** for 2D data, **6** for 3D data, etc.                                                 |
| <mark style="color:purple;background-color:purple;">**Experimentation**</mark>          | Start with a low value for **`min_samples`** and gradually increase it, observing changes in cluster quality.                                                                                                                                                                                 | Adjust based on clustering results: if noise is too high, increase **`min_samples`** slightly.        |
| **Dataset Density**                                                                     | Consider the density of data points in the dataset.                                                                                                                                                                                                                                           | **Dense data**: Lower `min_samples` (e.g., 4–5). **Sparse data**: Higher `min_samples` (e.g., 6–8).   |
| <mark style="color:purple;background-color:purple;">**Domain Knowledge**</mark>         | Use insights specific to your field to set an appropriate minimum density requirement.                                                                                                                                                                                                        | E.g., if clusters represent groups of 10 customers, set **`min_samples = 10`** to match expectations. |
