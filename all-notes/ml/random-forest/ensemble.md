# Ensemble

* We can use multiple instances of the same algorithm or combination of different algorithm
* Less possibility of bias
* Can also be used for regression
* Bagging – All will be of same algo, average will be taken
* Boosting – All can be same algo
* Weightage can be given to each algorithm, so that accordingly we can make a better decision

  * KNN

  * RF
