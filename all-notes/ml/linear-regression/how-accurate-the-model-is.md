# How Accurate the model is

* <mark style="color:purple;background-color:purple;">**R2 = ( 1 – RSS/TSS)**</mark>
* RSS – Residual sum of square, y - ypred
* TSS – Total sum of square, y - ymean
* If residuals is less then model will be better
* TSS will be constant for all the lines
* <mark style="color:purple;background-color:purple;">**If R2 = 0.9 then it means model is 90% accurate**</mark>
* <mark style="color:purple;background-color:purple;">**If RSS decrease then R2 will increase**</mark>
