# Data Cleaning

| **Task**                              | **Code**                                                                                                                                                                                                  | **Description**                                                        |
| ------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------- |
| **Check for Missing Values**          | <p><code>df.isnull().sum()</code><br><code>df.isnull().mean() * 100</code></p>                                                                                                                            | Count and percentage of missing values in each column                  |
| **Drop Rows with Missing Values**     | `df.dropna()`                                                                                                                                                                                             | Drop rows with any missing values                                      |
| **Drop Specific Column Missing Rows** | `df.dropna(subset=['column_name'])`                                                                                                                                                                       | Drop rows with missing values in a specific column                     |
| **Drop Columns with Missing Values**  | `df.dropna(axis=1)`                                                                                                                                                                                       | Drop columns with any missing values                                   |
| **Fill with Specific Value**          | `df['column_name'].fillna(0, inplace=True)`                                                                                                                                                               | Fill missing values with a specified value                             |
| **Fill with Mean/Median/Mode**        | <p><code>df['column_name'].fillna(df['column_name'].mean(), inplace=True)</code><br><code>df['column_name'].fillna(df['column_name'].median(), inplace=True)</code></p>                                   | Fill with the column mean, median, or mode                             |
| **Forward/Backward Fill**             | <p><code>df.fillna(method='ffill', inplace=True)</code><br><code>df.fillna(method='bfill', inplace=True)</code></p>                                                                                       | Fill missing values with the previous/next value                       |
| **Check for Duplicates**              | `df.duplicated().sum()`                                                                                                                                                                                   | Count duplicate rows                                                   |
| **Remove Duplicates**                 | `df.drop_duplicates(keep='first', inplace=True)`                                                                                                                                                          | Drop duplicate rows, keeping the first occurrence                      |
| **Identify Outliers (IQR Method)**    | <p><code>Q1 = df['col'].quantile(0.25)</code><br><code>Q3 = df['col'].quantile(0.75)</code><br><code>IQR = Q3 - Q1</code><br>`outliers = df[(df['col'] &#x3C; Q1 - 1.5 * IQR)</p>                         | (df\['col'] > Q3 + 1.5 \* IQR)]\`                                      |
| **Remove Outliers**                   | `df = df[(df['col'] >= Q1 - 1.5 * IQR) & (df['col'] <= Q3 + 1.5 * IQR)]`                                                                                                                                  | Filter out outliers                                                    |
| **Cap Outliers**                      | `df['col'] = np.where(df['col'] > Q3 + 1.5 * IQR, Q3 + 1.5 * IQR, np.where(df['col'] < Q1 - 1.5 * IQR, Q1 - 1.5 * IQR, df['col']))`                                                                       | Limit outliers to within 1.5 times the IQR                             |
| **Convert Data Types**                | <p><code>df['col'] = df['col'].astype(int)</code><br><code>df['col'] = df['col'].astype(float)</code><br><code>df['col'] = df['col'].astype('category')</code></p>                                        | Convert column to integer, float, or category                          |
| **Convert to Date**                   | `df['date_col'] = pd.to_datetime(df['date_col'])`                                                                                                                                                         | Convert a column to datetime                                           |
| **Extract Date Information**          | <p><code>df['year'] = df['date_col'].dt.year</code><br><code>df['month'] = df['date_col'].dt.month</code><br><code>df['day'] = df['date_col'].dt.day</code></p>                                           | Extract year, month, or day from a datetime column                     |
| **Standardize Text**                  | <p><code>df['text_col'] = df['text_col'].str.lower()</code><br><code>df['text_col'] = df['text_col'].str.strip()</code><br><code>df['text_col'] = df['text_col'].str.replace('[^a-zA-Z]', ' ')</code></p> | Standardize text by converting to lowercase, removing whitespace, etc. |
| **Split Text Column**                 | `df[['first_name', 'last_name']] = df['full_name'].str.split(' ', expand=True)`                                                                                                                           | Split a column into multiple columns                                   |
| **Extract Pattern**                   | `df['extracted'] = df['text_col'].str.extract(r'(pattern)')`                                                                                                                                              | Extract specific patterns using regular expressions                    |
| **Map Values**                        | `df['col'] = df['col'].replace({'old_val': 'new_val'})`                                                                                                                                                   | Replace specific values in a column                                    |
