# EDA

| **Task**                                   | **Code**                                                                                                                         | **Description**                                                 | **Data Type**             |
| ------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------- | ------------------------- |
| **View Basic Data Info**                   | `df.info()`                                                                                                                      | Summary of data types, non-null counts, and memory usage        | Both                      |
| **View Descriptive Statistics**            | `df.describe()`                                                                                                                  | Summary statistics (mean, std, min, etc.) for numerical columns | Numerical                 |
| **Display First/Last Rows**                | <p><code>df.head(5)</code><br><code>df.tail(5)</code></p>                                                                        | Display first or last few rows of the dataset                   | Both                      |
| **Check Column Types**                     | `df.dtypes`                                                                                                                      | List data types for each column                                 | Both                      |
| **Check Shape (Rows, Columns)**            | `df.shape`                                                                                                                       | Get number of rows and columns                                  | Both                      |
| **Count Unique Values**                    | `df['column_name'].nunique()`                                                                                                    | Count unique values in a column                                 | Categorical               |
| **Value Counts for Categorical Data**      | `df['column_name'].value_counts()`                                                                                               | Count occurrences of each category                              | Categorical               |
| **Correlation Matrix**                     | `df.corr()`                                                                                                                      | Compute pairwise correlation between numerical columns          | Numerical                 |
| **Pairplot**                               | <p><code>import seaborn as sns</code><br><code>sns.pairplot(df)</code></p>                                                       | Visualize pairwise relationships between numerical columns      | Numerical                 |
| **Heatmap for Correlations**               | `sns.heatmap(df.corr(), annot=True, cmap='coolwarm')`                                                                            | Display a heatmap of correlations                               | Numerical                 |
| **Distribution Plot**                      | `sns.histplot(df['column_name'], kde=True)`                                                                                      | Plot distribution of a numerical column                         | Numerical                 |
| **Boxplot for Outliers**                   | `sns.boxplot(x=df['column_name'])`                                                                                               | Identify outliers in a column using a boxplot                   | Numerical                 |
| **Countplot for Categorical Data**         | `sns.countplot(x='column_name', data=df)`                                                                                        | Visualize frequency of categories in a column                   | Categorical               |
| **Scatter Plot**                           | `plt.scatter(df['col1'], df['col2'])`                                                                                            | Scatter plot to show relationship between two columns           | Numerical                 |
| **Group by and Aggregate**                 | `df.groupby('category_col')['value_col'].mean()`                                                                                 | Group by categorical column and calculate aggregate statistics  | Categorical and Numerical |
| **Pivot Table**                            | `pd.pivot_table(df, values='value_col', index='index_col', columns='columns_col', aggfunc='mean')`                               | Create pivot table for deeper insights                          | Categorical and Numerical |
| **Plot Missing Values**                    | <p><code>import missingno as msno</code><br><code>msno.matrix(df)</code></p>                                                     | Visualize missing values in the dataset                         | Both                      |
| **Visualize Outliers in Multiple Columns** | `sns.boxplot(data=df[['col1', 'col2', 'col3']])`                                                                                 | Boxplot to check outliers across multiple columns               | Numerical                 |
| **Bar Plot of Categorical vs Numeric**     | `sns.barplot(x='category_col', y='numeric_col', data=df)`                                                                        | Compare numeric values across categories                        | Categorical and Numerical |
| **Cross-tabulation**                       | `pd.crosstab(df['cat_col1'], df['cat_col2'])`                                                                                    | Cross-tabulate counts between two categorical columns           | Categorical               |
| **Time Series Plot**                       | <p><code>df['date_col'] = pd.to_datetime(df['date_col'])</code><br><code>df.set_index('date_col')['value_col'].plot()</code></p> | Line plot for time series data                                  | Numerical (Time Series)   |
| **Density Plot**                           | `sns.kdeplot(df['numeric_col'])`                                                                                                 | Display density plot for a continuous variable                  | Numerical                 |
| **Boxplot for Numeric by Categorical**     | `sns.boxplot(x='category_col', y='numeric_col', data=df)`                                                                        | Compare distributions of a numeric variable across categories   | Categorical and Numerical |
| **Violin Plot for Distribution**           | `sns.violinplot(x='category_col', y='numeric_col', data=df)`                                                                     | Show distribution and density of a numeric variable by category | Categorical and Numerical |
| **Calculate Skewness/Kurtosis**            | <p><code>df['numeric_col'].skew()</code><br><code>df['numeric_col'].kurt()</code></p>                                            | Measure skewness and kurtosis of a numerical column             | Numerical                 |
