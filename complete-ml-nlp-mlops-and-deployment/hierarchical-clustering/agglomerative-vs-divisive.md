# Agglomerative vs Divisive



| Feature                                | Agglomerative Clustering                                                                                                                                                            | Divisive Clustering                                                                                                                                                                                |
| -------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Basic Approach**                     | <mark style="color:purple;background-color:purple;">**Starts with each data point as its own cluster; merges clusters iteratively.**</mark>                                         | <mark style="color:purple;background-color:purple;">**Starts with all data points in one cluster; splits clusters iteratively.**</mark>                                                            |
| **Process**                            | <mark style="color:purple;background-color:purple;">**Bottom-up**</mark>: merges the closest clusters at each step until a single cluster is formed or a stopping criterion is met. | <mark style="color:purple;background-color:purple;">**Top-down**</mark>: splits the largest or most heterogeneous cluster until each data point is its own cluster or a stopping criterion is met. |
| **Computational Complexity**           | Generally more efficient and commonly used; typical complexity is ( O(n^2 \log n) ) or better with optimizations.                                                                   | Generally less efficient due to more complex splitting; typical complexity is ( O(2^n) ), making it less practical for large datasets.                                                             |
| **Dendrogram**                         | Builds from the bottom up; the dendrogram starts with individual data points and merges them into clusters.                                                                         | Builds from the top down; the dendrogram starts with one cluster and splits it until each point is a separate cluster.                                                                             |
| **Cluster Merging/Splitting Decision** | Merges based on a linkage criterion like single, complete, average, or Ward’s linkage.                                                                                              | Splits based on criteria such as maximizing dissimilarity within a cluster or using divisive methods like k-means recursively.                                                                     |
| **Usage in Practice**                  | More commonly used due to simplicity and efficiency, especially with small to medium datasets.                                                                                      | Less commonly used, often limited to small datasets or specific applications where top-down insight is required.                                                                                   |
| **Interpretability**                   | Easier to interpret because clusters start as small and grow into larger, more natural groupings.                                                                                   | Can be insightful for understanding large-scale structures before reaching granular levels but can be more difficult to interpret.                                                                 |
| **Example Application**                | Often used in gene expression data clustering, customer segmentation, or document clustering.                                                                                       | Used in rare cases for hierarchical visualization in very small datasets or certain divisive tree-building algorithms.                                                                             |
