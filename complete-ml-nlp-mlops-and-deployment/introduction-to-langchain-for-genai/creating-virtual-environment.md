# ✈️ Creating Virtual Environment

* Open the Project folder with VS code
* Open Terminal ⇒ Command Terminal
* conda create -p venv python==3.10 -y
* requirements.txt
  * langchain
  * ipykernel ⇒ allows you to utilize different kernels from various virtual environments while running Jupyter Notebook in a separate environment
* conda activate venv
* pip install -r requirements.txt
