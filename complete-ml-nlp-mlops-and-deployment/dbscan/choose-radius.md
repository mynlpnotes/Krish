# Choose radius

| **Method**                                                                      | **Description**                                                                                                                                                                                                                                                                                                                                                                                                                   | **Recommendation**                                                                                           |
| ------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------ |
| <mark style="color:purple;background-color:purple;">**k-Distance Graph**</mark> | Plot distances to the k-th nearest neighbor (where k = `min_samples - 1`) and find the "elbow" point.                                                                                                                                                                                                                                                                                                                             | Look for a sharp increase in the plot (elbow) and choose `ε` at this point.                                  |
| <mark style="color:purple;background-color:purple;">**Domain Knowledge**</mark> | Use insights from your field to estimate a meaningful neighborhood distance.                                                                                                                                                                                                                                                                                                                                                      | Set `ε` based on relevant distance units (e.g., geographic distance, similarity in customer features, etc.). |
| <mark style="color:purple;background-color:purple;">**Experimentation**</mark>  | <mark style="color:purple;background-color:purple;">**Start with a low**</mark><mark style="color:purple;background-color:purple;">**&#x20;**</mark><mark style="color:purple;background-color:purple;">**`ε`**</mark><mark style="color:purple;background-color:purple;">**&#x20;**</mark><mark style="color:purple;background-color:purple;">**value and incrementally increase, evaluating cluster quality each time.**</mark> | Adjust `ε` and examine the balance of cluster cohesion and amount of noise points.                           |
| **Silhouette or Similar Metrics**                                               | Try different `ε` values, compute silhouette scores for each, and select the value that maximizes the score.                                                                                                                                                                                                                                                                                                                      | Use the `ε` that achieves the highest silhouette score to ensure well-separated and cohesive clusters.       |
