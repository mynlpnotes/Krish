# Entropy vs Gini

| **Aspect**                | **Entropy**                                                                                                                                                                                                            | **Gini Impurity**                                                                                                                                                                                        |
| ------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Definition**            | Measures the impurity by the unpredictability of the class label distribution.                                                                                                                                         | Measures the impurity by how often a randomly chosen element would be incorrectly classified.                                                                                                            |
| **Formula**               | $$( \text{Entropy}(S) = - \sum_{i=1}^{C} p_i \log_2(p_i) )$$                                                                                                                                                           | $$( \text{Gini}(S) = 1 - \sum_{i=1}^{C} p_i^2 )$$                                                                                                                                                        |
| **Range**                 | $$0 to (\log_2(C))$$                                                                                                                                                                                                   | 0 to 0.5 for binary classification                                                                                                                                                                       |
| **Interpretation**        | Higher entropy means more uncertainty.                                                                                                                                                                                 | Higher Gini impurity means more impurity (more mixed classes).                                                                                                                                           |
| **Value at Pure Node**    | <mark style="color:purple;background-color:purple;">**0**</mark> (if the node is pure, all samples belong to the same class).                                                                                          | <mark style="color:purple;background-color:purple;">**0**</mark> (if the node is pure, all samples belong to the same class).                                                                            |
| **Value at Max Impurity** | <mark style="color:purple;background-color:purple;">**(**</mark> $$\log_2(C)$$ <mark style="color:purple;background-color:purple;">**)**</mark> (for C classes, maximum entropy when classes are equally distributed). | <mark style="color:purple;background-color:purple;">**(**</mark> $$\frac{C-1}{C}$$<mark style="color:purple;background-color:purple;">**)**</mark> (maximum value when classes are equally distributed). |
| **Use Case**              | Often used in <mark style="color:purple;background-color:purple;">**ID3 and C4.5**</mark> decision trees.                                                                                                              | Commonly used in <mark style="color:purple;background-color:purple;">**CART (Classification and Regression Trees).**</mark>                                                                              |
