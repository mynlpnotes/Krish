# Soft margin and Hard margin

* &#x20;In real world, the classes wont be much separable, there can be some overlapping as well
* So in such scenario we wont be having perfect best fit line
* There will be some kind of error, this is knows as soft margin
* If it clearly separable and there is no overlapping then it will be called as hard margin
* <mark style="color:purple;background-color:purple;">**Soft Margin   - There can be overlapping of classes**</mark>
* <mark style="color:purple;background-color:purple;">**Hard Margin - Clearly separable**</mark>
