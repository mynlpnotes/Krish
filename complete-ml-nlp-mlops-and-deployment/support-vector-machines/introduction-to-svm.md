# Introduction to SVM

* SVR for <mark style="color:purple;background-color:purple;">**regression**</mark>
* SVC for <mark style="color:purple;background-color:purple;">**classification**</mark>
* In logistic regression our aim is to create a line which can separate the classes
* In SVM, specially in SVC <mark style="color:purple;background-color:purple;">**along with the best fit line, we also try to create 2 more lines, which are known as marginal plane**</mark>
* <mark style="color:purple;background-color:purple;">**This marginal should be created such that the distance between the marginal plane is maximum**</mark>
* Out of the two margins below, we will select left one as d is greater there
* <mark style="color:purple;background-color:purple;">**Marginal plane passes through the nearest point of the classes, this are known as support vectors**</mark>
* In 3D coordinates, we will be create a plane, and it will have 2 marginal planes above and below it
